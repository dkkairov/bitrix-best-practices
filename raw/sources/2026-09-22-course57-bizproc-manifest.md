## Как проверить, изменился ли урок

В каждой странице урока есть разметка schema.org (`<script type="application/ld+json">`, тип
`Article`): `dateModified`, `datePublished` и `articleBody` — HTML урока, экранированный дважды.
Хэш считается от текста урока без разметки:

```python
import hashlib, html, json, re, urllib.request

def lesson(url):
    page = urllib.request.urlopen(url).read().decode('utf-8')
    ld = json.loads(re.search(r'<script type="application/ld\+json">\s*(\{.*?"@type":"Article".*?\})\s*</script>',
                              page, re.S).group(1))
    body = html.unescape(html.unescape(ld['articleBody']))
    body = re.sub(r'(?is)<(script|style)\b.*?</\1>', ' ', body)
    body = re.sub(r'(?i)<br\s*/?>|</p>|</li>|</h\d>|</tr>|</div>', '\n', body)
    text = html.unescape(re.sub(r'<[^>]+>', ' ', body)).replace('\u00a0', ' ')
    text = re.sub(r'\n\s*', '\n', re.sub(r'[ \t\r\f\v]+', ' ', text)).strip()
    return ld['dateModified'], len(text), hashlib.sha256(text.encode('utf-8')).hexdigest()[:16]
```

Хэш проверен на повторной загрузке трёх уроков — совпал. Новые и пропавшие уроки видны по
оглавлению (левое меню любой страницы курса).

Колонки: «Где» — путь по оглавлению (главы), «Изменён» — `dateModified`, «Знаков» — длина текста
урока без разметки.
