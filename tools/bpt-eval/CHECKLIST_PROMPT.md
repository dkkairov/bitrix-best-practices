# Задание проверяющему чек-лист (подставить {{README_PATH}}, {{ITEMS}}, {{OUT}})

Прочитай README решения: {{README_PATH}}. Для каждого пункта ниже ответь, поднят ли он в README —
как вопрос заказчику, допущение или принятое решение. Засчитывай только явное упоминание по смыслу;
цитата из README обязательна (до 200 символов, дословно), без цитаты — raised: false.

Пункты:
{{ITEMS}}

Результат — это файл, а не ответ в чат: инструментом записи файла создай (или перезапиши) {{OUT}} с
содержимым — ровно этот JSON и ничего больше:
{"items": [{"text": "<пункт как есть>", "raised": true, "quote": "<цитата>"}]}

Требования к JSON — файл должен разобраться парсером без ошибок:
- только валидный JSON в кодировке UTF-8: никакого markdown (без ```), никакого текста до или после;
- кавычки `"`, обратные слэши `\` и переводы строк внутри цитаты обязательно экранируй (`\"`, `\\`, `\n`) —
  не разобравшийся JSON засчитывается как raised: false по всем пунктам;
- если дословная цитата не помещается в 200 символов или её нельзя аккуратно экранировать — обрежь до
  ближайшей целой фразы, но не выходи за границу JSON-строки.
Задание не выполнено, если JSON есть только в ответе в чате, а файл {{OUT}} не создан или не обновлён —
именно файл читает прогонщик. Больше ничего не делай и не меняй.
