# wiki-lint — механические проверки вики

Проверяет то, что можно проверить машиной: ссылки, связность, frontmatter, имена файлов, структуру
папок, полноту хабов и навигатора, даты и следы секретов. Правила — из [CLAUDE.md](../../CLAUDE.md)
(§4 соглашения страниц, §5 перелинковка, §6 доверие и жизненный цикл, §9 домен).

Разбор «глазами» — противоречия между страницами, устаревшие практики, несоответствие `edition`
тексту, пробелы покрытия — остаётся за командой `/wiki:lint`; утилита закрывает её механическую часть.

**Требования:** PHP ≥ 8.1 (`mbstring`, `json`). Запуск — из корня репозитория.

## Запуск

```bash
php tools/wiki-lint/wiki-lint.php
```

| Ключ | Что делает |
|------|-----------|
| `--root=<путь>` | корень репозитория, если запускаете не из него |
| `--only=<проверка>` | одна проверка: `brokenLinks`, `orphans`, `frontmatter`, `verified`, `naming`, `structure`, `hubs`, `aliases`, `navigator`, `dates`, `secrets`, `coverage` |
| `--json` | вывод в JSON: `stats` и `findings` |
| `--strict` | предупреждения тоже дают код выхода 1 |
| `--today=ГГГГ-ММ-ДД` | дата для проверки «протухания» `verified` (по умолчанию сегодня) |
| `--help` | справка |

**Коды выхода:** `0` — ошибок схемы нет, `1` — есть (со `--strict` считаются и предупреждения),
`2` — неверные аргументы или не найден корень вики.

## Что проверяется

| Проверка | Уровень | Правило |
|---|---|---|
| `brokenLinks` | 🔴 | каждая `[[ссылка]]` резолвится в файл или `aliases`; код в блоках и `\|` в таблицах игнорируются |
| `orphans` | 🔴 | у контент-страницы ≥ 1 входящая ссылка (считаются и `index.md`, `log.md`, `README.md`) |
| `frontmatter` | 🔴 | ядро полей на месте, `edition` и `status` из допустимых значений |
| `naming` | 🔴 | имя `<тип>-слаг`, префикс соответствует `type`, имя уникально в вики |
| `structure` | 🔴 | страницы лежат плоско в папке раздела, без подпапок по типам |
| `hubs` | 🔴 | у папки есть `_index-*`, и он перечисляет все её страницы |
| `aliases` | 🔴 | alias не дублируется и не совпадает с именем другой страницы |
| `navigator` | 🔴 | каждая контент-страница упомянута в `index.md` |
| `secrets` | 🔴 | нет вебхуков, токенов и приватных ключей (§4.4) |
| `verified` | 🟡 | при `status: verified` поле `verified` заполнено и не старше полугода |
| `dates` | 🟡 | `updated` не в будущем, `verified` не новее `updated` |
| `coverage` | 🔵 | разделы, где меньше трёх страниц |

Исключения зашиты в код: папка `wiki/_templates/` не проверяется, у хабов `_index-*` и у
`sources-backlog` нет префикса-типа, хабы не считаются орфанами.

## Тесты

```bash
php tools/wiki-lint/tests/run.php [--filter=<часть имени>]
```

Тесты собирают временную вики из нескольких файлов и проверяют, что каждая проверка ловит свою
поломку и молчит на здоровой вики. Настоящая вики репозитория в тестах не используется.

## Как устроено

| Файл | Ответственность |
|------|-----------------|
| `wiki-lint.php` | разбор аргументов, запуск, код выхода |
| `src/Page.php` | одна страница: frontmatter, тело, исходящие ссылки |
| `src/Wiki.php` | загрузка вики, индексы имён и алиасов, счётчик входящих ссылок |
| `src/Checks.php` | сами проверки; каждая возвращает список `Finding` |
| `src/Report.php` | текстовый и JSON-отчёт, статистика, наличие ошибок |

Добавить проверку: метод в `Checks`, возвращающий `list<Finding>`, вызов в `Checks::all()`, строка в
таблице выше и тест в `tests/checks_test.php`.
