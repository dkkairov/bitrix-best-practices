# Playbooks — пошаговые сценарии по жизненному циклу

Сквозные сценарии внедрения по этапам: пресейл/аудит → проектирование → настройка/деплой →
миграция данных → обучение и адаптация → поддержка.

## Этапы
- Пресейл и аудит
- Проектирование решения
- Настройка и запуск (деплой)
- Миграция данных
- Обучение и адаптация пользователей
- Поддержка и развитие

## Страницы
- [[checklist-presale-audit|Playbook предпроектного аудита]]
- [[checklist-requirements-workshop|Playbook рабочей встречи по требованиям и её разбора]]

## Статус покрытия
Есть аудит и разбор рабочей встречи по требованиям. Не хватает: деплой «под ключ», миграция
данных, обучение, регламент поддержки.
