# Playbooks — пошаговые сценарии по жизненному циклу

Сквозные сценарии внедрения по этапам: пресейл/аудит → проектирование → настройка/деплой →
миграция данных → обучение и адаптация → поддержка.

## Этапы
- Пресейл и аудит
- Проектирование решения
- Настройка и запуск (деплой)
- Миграция данных
- Обучение и адаптация пользователей
- Поддержка и развитие

## Статус покрытия
Жизненный цикл закрыт целиком: аудит → требования → миграция → запуск → адаптация → поддержка.
Четыре новых playbook'а — в статусе `draft`: это каркасы, которые команда уточняет после
первого применения на реальном проекте (пороги, роли, сроки реакции, формулировки приёмки).
Не хватает: разбора инцидентов на стороне заказчика, шаблонов клиентских документов.
