# Локализация: Loc, языковые файлы, ленивая загрузка

**TL;DR:** текст интерфейса не пишем в коде — выносим во фразы. `Bitrix\Main\Localization\Loc`
берёт их из файла `lang/<язык>/<то же имя, что у скрипта>.php`, который ядро подхватывает само.
Совпадение путей — не формальность: на нём держится ленивая загрузка.

**Когда важно:** свой модуль, компонент, страница в админке, письма — всё, что видит пользователь.
Разовый служебный скрипт можно оставить на русском.

## Как устроено

```php
// /local/php_interface/classes/Import.php
use Bitrix\Main\Localization\Loc;

Loc::loadMessages(__FILE__);

echo Loc::getMessage('VENDOR_IMPORT_DONE', ['#COUNT#' => $n]);
```

```php
// /local/php_interface/lang/ru/classes/Import.php
$MESS['VENDOR_IMPORT_DONE'] = 'Импортировано записей: #COUNT#';
```

- Файл перевода лежит в `lang/<код языка>/` **по тому же относительному пути и с тем же именем**,
  что исходный файл.
- Подстановка — массивом `['#COUNT#' => $n]`; в фразе те же ключи.
- Кодировка — **UTF-8 без BOM**.

| Метод | Зачем |
|---|---|
| `getMessage($code, $replace, $language)` | получить фразу |
| `getMessagePlural($code, $value, $replace, $language)` | множественные формы: «1 задача / 2 задачи / 5 задач» |
| `loadMessages(__FILE__)` | подключить файл фраз текущего скрипта |
| `loadLanguageFile($path, $language)` | подключить конкретный файл |
| `getCurrentLang()`, `getDefaultLang()`, `setCurrentLang()` | язык интерфейса |
| `loadLazy($code)` | точечная догрузка фразы по коду |

`getMessagePlural` документация не упоминает, но метод в ядре есть (26.750.0) — для счётчиков берём
его, а не три отдельных кода фраз.

## Ленивая загрузка и её цена

Ядро сопоставляет файл фраз по пути вызывающего скрипта. Пути не совпали — фраза всё равно
найдётся, но ценой перебора: ядро начнёт последовательно грузить языковые файлы в поисках кода.
На странице с сотней таких фраз это заметно.

Отладка: включаем константу `BX_MESS_LOG` — ядро запишет, какие фразы искались перебором.

## Ловушки

- **Переименовали файл — перенесите и перевод.** Иначе тихая деградация: работает, но медленно.
- **`$MESS` — глобальный массив,** коды фраз глобальны. Префикс по модулю (`VENDOR_IMPORT_*`)
  обязателен, иначе чужая фраза перекроет вашу.
- **Фраза без перевода возвращает пустую строку**, а не код. В интерфейсе это выглядит как
  «пропала кнопка», поэтому после добавления фраз проверяем все языки сайта.
- **Не собираем предложения из кусков.** «Найдено» + число + «записей» не переводится на языки с
  другим порядком слов — одна фраза с подстановками.
- **Письма и печатные формы** тоже локализуются: у шаблона письма свой язык, и он может не
  совпадать с языком интерфейса.
- **Свой модуль** кладёт фразы в `lang/` рядом с `install/`, `lib/`, `admin/`
  ([[recipe-module-structure-and-install]]).
