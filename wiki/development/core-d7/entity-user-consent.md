# UserConsent — согласия пользователей в формах

**Что это:** механизм ядра для сбора и хранения согласий — на обработку персональных данных,
cookie, аналитику. Класс `Bitrix\Main\UserConsent\Consent`, компонент
`bitrix:main.userconsent.request`.

**Зачем помнить:** собственная галочка «согласен» в форме юридически ничего не значит — нет текста,
которому пользователь сказал «да», и нет доказательства. Штатный механизм фиксирует **версию
текста, источник и выбранные пункты**.

## Как заводится

1. Настройки → Настройки продукта → Соглашения. Два типа: **стандартное** (готовый текст с
   редактируемыми блоками) и **собственное** (свой текст или ссылка на внешний документ).
2. В форме подключается компонент `bitrix:main.userconsent.request` с параметрами `ID`,
   `IS_CHECKED`, `IS_LOADED`, `AUTO_SAVE`.
3. В своём компоненте достаточно объявить `'USER_CONSENT' => []` в `.parameters.php` — секция
   согласия появится в настройках компонента.

Сохранение: либо автоматически (`AUTO_SAVE = 'Y'`), либо по событию
`BX.UserConsent.events.save` — когда форму отправляет свой JS.

## API

```php
\Bitrix\Main\UserConsent\Consent::addByContext($agreementId, $originatorId, $originId, $params);
```

Ядро находит соглашение, проверяет источник и записывает факт согласия вместе с выбранными
пунктами (`ITEMS`).

**Источники** регистрируются обработчиком события `OnUserConsentProviderList`: у источника есть
`CODE`, `NAME`, `DATA` (название и адрес формы) и `ITEMS` (тексты пунктов). Так в списке согласий
видно не «форма №17», а понятное имя.

## Правила

- **Записи о согласиях не удаляются** — это требование к доказательству, а не недоработка
  интерфейса.
- **Текст соглашения меняем версией, а не правкой.** Иначе старые согласия окажутся выданными на
  текст, которого пользователь не видел.
- **Согласие — не универсальная галочка.** Отдельно обработка персональных данных, отдельно
  рассылка, отдельно cookie: пользователь должен иметь возможность согласиться не на всё.
- **Свои формы (в том числе на REST) тоже подпадают** под это требование — если форма собирает
  контакты, согласие нужно ([[pattern-rest-webhooks-and-events]]).
- Юридические формулировки согласуем с заказчиком: наша зона — механизм и доказуемость, его —
  текст.
