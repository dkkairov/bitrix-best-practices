# Выражения БП: вставка значения, функции, модификаторы, коды

**TL;DR:** в любом поле действия можно подставить значение (`{=Префикс:Код}` или `{{Имя поля}}`),
вычислить формулу (`=…` на всё поле или `{{=…}}` внутри текста) и преобразовать результат
модификатором (`> printable`). Ошибка в выражении процесс не останавливает — выражение выводится как
текст, поэтому выражения проверяют прогоном. Справка собрана по главе курса 57
[«Форма «Вставка значения»»](https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=57&LESSON_ID=12383).

> **Проверено на стенде** (коробка, bizproc 26.1075.0, 2026-09-22): синтаксис, системные значения,
> функции всех групп, модификаторы пользователя, ошибка в выражении и «одно Изменение документа» —
> прогоном процесса на элементе. Модификаторы файлов, коды групп и привязок задач — по курсу. Как
> выражения лежат в файле шаблона — [[concept-bizproc-bpt-format]].
>
> **Изменено 2026-09-22 по итогам прогона.** `true`, `false`, `and`, `or`, `not` — функции, а не
> операторы, как у курса (урок 4912); `%` — процент; в ядре есть `jsonval`, которой нет в курсе;
> суффикс `_printable` работает только строчными.

## Синтаксис
- `{=Document:TITLE}` — значение по коду; `{{Название}}` — то же по имени поля, так его показывает
  дизайнер.
- `=выражение` в начале поля — поле целиком вычисляется; `{{=выражение}}` — результат вставляется в
  текст, вставок в одном поле может быть несколько.
- Вложенная функция пишется без `{{ }}` и без `=`: `=dateadd(touserdate('user_6', {=System:Now}), "1d")`.
- Строки склеиваются `&`; текст — в `"…"` или `'…'`; если в тексте есть кавычки, внешние — другого вида.
- Имена функций не зависят от регистра.
- Одно «Изменение документа» видит **старые** значения полей: зависимый расчёт — через переменную
  ([урок 5359](https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=57&LESSON_ID=5359)).

## Разделы «Вставки значения» и префиксы
| Раздел формы | Запись |
|---|---|
| Параметры шаблона | `{=Template:код}` — вводит запускающий |
| Переменные | `{=Variable:код}` |
| Константы | `{=Constant:код}` |
| Глобальные константы и переменные | выбираются в форме (в меню помечены «@») |
| Поля документа | `{=Document:КОД}` |
| Дополнительные результаты | `{=A…:Результат}` — по имени действия; группируются по заголовку действия |
| Пользователи, категории | `user_N`, коды групп (ниже); несколько — через `;` |

Кого видно в «Пользователях», зависит от прав на документ: для шаблона CRM нужна роль не ниже «Чтение»
к сущности, выданная группе или пользователю, а не отделу.

## Системные значения
| Запись | Что это |
|---|---|
| `{=Workflow:ID}` | ID процесса — для ссылки на задание |
| `{=Template:TargetUser}` | кто запустил процесс (`user_N`) |
| `{=User:ID}` | пользователь текущего хита — после паузы или на агенте им может оказаться кто угодно |
| `{=System:Now}` | дата и время сервера (облако RU — UTC+3) |
| `{=System:NowLocal}` | дата и время пользователя |
| `{=System:Date}` | дата сервера без времени |
| `{=System:Eol}` | перенос строки — там, где не работает `[br]` |
| `{=System:HostUrl}` | адрес сайта, с bizproc 22.200.0 — вместо домена в тексте |

Интерфейс всегда показывает время в поясе того, кто смотрит.

## Функции калькулятора
Операторы: `+ - * /`, `=` (равно), `<>`, `< > <= >=`, `&` (склейка), `^` (степень), скобки и `%` —
процент, а не остаток: `200 * 10%` = 20, `50%` = 0.5 (стенд, код ядра). Курс
([урок 4912](https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=57&LESSON_ID=4912)) относит к
операторам и `true`, `false`, `and`, `or`, `not`, но в ядре это функции: `true()`, `if(and(a, b), …)`,
`or(a, b)`, `not(a)`. Голое `true` и запись `1 and 0` не разбираются — выражение выводится текстом.

| Группа | Функции | На что обратить внимание |
|---|---|---|
| Даты | `dateadd`, `datediff`, `date`, `locdate`, `strtotime`, `settime` | число единиц для `dateadd` из переменной — только склейкой: `{=Variable:n} & "d"`; `datediff(дата1, дата2, формат)` — без формата пусто, итог в днях — `"%a"`; `locdate` — названия на языке сайта (месяц — «22 Сентября 2026»); `settime` — с 22.500.0 |
| Рабочее время | `workdateadd`, `addworkdays`, `isworkday`, `isworktime` | `workdateadd` считает дни, часы, минуты по рабочему времени пользователя (параметр — с 19.0.0); выходные — по настройкам портала |
| Часовые пояса | `touserdate`, `getuserdateoffset` | переводят время сервера в пояс пользователя |
| Числа | `abs`, `intval`, `floatval`, `round`, `ceil`, `floor`, `min`, `max`, `rand`, `numberformat` | `numberformat(число, знаков, разделитель, разделитель тысяч)` |
| Строки | `substr`, `strpos`, `strlen`, `trim`, `strtolower`, `strtoupper`, `ucfirst`, `ucwords`, `urlencode`, `randstring`, `jsonval` | отсчёт позиций с нуля, кириллица считается по символам (`strlen("Привет")` = 6); регистр — с 21.200.0, `trim` — с 22.300.0; `jsonval(путь, json)` — значение по пути через точку (`"a.b.1"`), курс её не описывает |
| Множественные | `implode`, `explode`, `merge`, `shuffle`, `firstvalue`, `swirl` | `firstvalue(explode(',', …))` — первое значение строки |
| Логика и ссылки | `if(условие, да, нет)`, `true()`, `false()`, `and`, `or`, `not`, `getdocumenturl('bb' \| 'html', полная)` | `getdocumenturl` — с 22.200.0, ссылка на текущий документ; «полная» — `1`, не `true`; без второго аргумента ссылка относительная, с другим форматом — просто адрес |

Пример: `=if(isworkday({=System:Now}), dateadd({=System:Now}, "1d"), addworkdays({=System:Now}, 1))`.

## Модификаторы
Пишутся через `>` внутри скобок, несколько — через запятую: `{=Variable:dt > date, printable}`
([урок 12407](https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=57&LESSON_ID=12407)).

| Модификатор | Для чего |
|---|---|
| `printable` | понятная человеку строка («Имя Фамилия [1]» вместо кода) |
| `friendly` | пользователь — только имя и фамилия |
| `name` | файл — его имя (с 20.100.0) |
| `server`, `local`, `responsible` | дата — в поясе сервера, пользователя, ответственного |
| `publink`, `shortlink` | файл — публичная или короткая ссылка (с 20.0.700) |
| `src` | файл — прямая ссылка; в коробке небезопасна |
| `file` | файл Диска как обычный файл — например, для вложения в письмо |
| `bool`, `date`, `datetime`, `double`, `int`, `select`, `string`, `text`, `user` | приведение типа; допустимые пары — таблица в уроке 12407 |

Старые формы: суффикс `_printable` у кода (`{=Variable:user_printable}`) и приписка `(текст)` у имени
поля — для полей «не для печати», например телефона CRM: без неё в текст попадёт «Array». Суффикс —
только строчными: `{=Document:ASSIGNED_BY_ID_printable}` работает, `_PRINTABLE` даёт пусто (стенд).

## Коды пользователей, групп и привязок
- Пользователь — `user_N`; с переменным ID — `="user_" & {=Variable:id}`.
- Группы — `group_G7`, `group_U7`, `group_IU7`, `group_SU7`, `group_UA`, отделы `group_D7` / `group_DR7`
  (без / с подотделами), `group_Dextranet`, роли рабочей группы `group_SG7_A/E/K`
  ([урок 13640](https://dev.1c-bitrix.ru/learning/course/?COURSE_ID=57&LESSON_ID=13640)). Регистр части
  после `group_` не важен — ядро приводит её к верхнему; с 25.200.0 подразделения — из
  `humanresources`, их ID могут отличаться от прежних.
- Код группы в поле для одного пользователя даёт её пользователя с наименьшим ID.
- Привязка задачи к CRM из не-CRM действий: `C_` (контакт), `D_` (сделка), `L_` (лид), `CO_` (компания),
  `SI_` (счёт), смарт-процесс — `T` + ID типа в шестнадцатеричном виде строчными: `="Tae_" & {{ID}}`.

## Почему важно при внедрении
- Генерация шаблона агентом: выражения собираются из этих кирпичей, а ошибка не видна до прогона.
- Перенос: `{=System:HostUrl}` и `getdocumenturl()` вместо адреса портала
  ([[antipattern-bizproc-hardcoded-portal-ids]]).
- Часовые пояса и `{=User:ID}` — частая причина «в письме не то время» и «не тот пользователь».

## Облако vs коробка
Синтаксис один. Различаются время сервера (облако RU — UTC+3), безопасность `src` (в коробке — нет) и
видимость свойств инфоблока (коробка: свойство видно, если для него включён фильтр в списке
элементов).
