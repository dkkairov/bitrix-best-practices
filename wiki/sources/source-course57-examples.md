## TL;DR
Около пятнадцати разобранных процессов: согласование подотчётных денег, заявки на закупку на списках,
счёт в CRM процессом со статусами, заявка на отпуск, обслуживание лидов, доработка типовых процессов, и
семь готовых шаблонов `.bpt` для импорта. Примеры хорошо показывают приёмы, но роли в них часто зашиты
группами в действия или ID, а «PHP код» подставляет значения прямо в текст — брать как иллюстрацию, не
копировать.

## Ключевые тезисы
- **Сроки.** «Период утверждения» (например, 5 дней) по истечении автоматически отклоняет документ, и
  процесс идёт по ветке отказа (2792). Пустой период — ожидание без конца (2793). «Срок» из 6851 — лишь
  проверка условием после того, как задание выполнено: процесс при этом может ждать вечно.
- **Роли.** Встречаются все способы: параметр запуска `TargetUser`, группы прямо в действии,
  переменные со значением по умолчанию, константы типовых шаблонов (`Manager`, `BookkeeperPay` в
  «Заявлении на отпуск»), поля документа, результат «Выбора сотрудника». Курс советует держать роли в
  переменных, чтобы заменить исполнителя сразу по всему шаблону (5272, 5384).
- **«Выбор сотрудника» для отпуска (5518).** Тип «начальник» для автора, уровень 1, резерв — переменная
  с директором, пропуск отсутствующих.
- **Импорт готовых шаблонов.** Импортированный шаблон обязательно сверить и настроить. После импорта
  CRM-шаблона (5383) у полей «Привязка к элементам CRM» «Доступная сущность» сбрасывается на «Лид» —
  выставить вручную. В примере во всех ролях стоит пользователь с ID 1 — только для теста. Шаблон для
  списка после импорта требует замены полей во всех действиях и текстах (5518).
- **Условия и списки.** Ветки проверяются слева направо, «Истина» работает как «иначе». Одна
  переменная-список не обслуживает две ветки с разными наборами вариантов (7107). Варианты списка с
  кодом пишут как `[код]Название`.
- **«PHP код» в примерах.** В 5368 значения подставлены в текст кода без кавычек — код в показанном
  виде не выполнится и открыт для инъекции; в 8411 ID исполнителя и постановщика зашиты числами. Для
  8411 есть штатная альтернатива — «Поставить задачу» с остановкой процесса и признаком важности.
- **Хиты.** Процесс выполняется на хитах; для точности по времени на портале должны быть хиты (6851).

## Противоречия и оговорки
- 2792: в тексте «Любой сотрудник», на скриншоте «Все сотрудники».
- 5384: на первом этапе стадия сделки меняется, а процесс идёт дальше — значит, не действием «Сменить
  стадию» (оно завершает процесс), а изменением поля. Готовый `crm_bp.bpt` из урока не скачивали: на
  загрузку файлов нужно разрешение пользователя.
- 6851: про хиты — для коробки с агентами на cron и для облака формулировка устарела.
