## TL;DR
«Язык значений» бизнес-процесса: как подставлять поля, переменные и результаты действий, 19 операторов
и 40 функций калькулятора, 9 модификаторов вывода и 10 преобразований типов, коды пользователей,
групп и элементов CRM. Главная ловушка: выражение с ошибкой не останавливает процесс, а выводится
текстом. Урок 8445 разбирает пять ошибок проектирования, которые нагружают портал, и называет лимит —
не больше двух экземпляров процесса на документ одновременно (облако).

## Ключевые тезисы
- **Синтаксис.** `=` в начале поля — поле вычисляется; `{{=…}}` — результат вставляется в текст, таких
  вставок в поле может быть несколько. Значение подставляется кодом `{=Префикс:Код}` или именем поля
  `{{Имя поля}}`. Строки склеиваются `&`. Вложенная функция пишется без `{{ }}` и без `=`. Имена
  функций не зависят от регистра.
- **Ошибка не видна.** Выражение с неверным синтаксисом выводится как текст, без сообщения; частая
  причина — неверные фигурные скобки.
- **Системные значения.** `{=Workflow:ID}`, `{=Template:TargetUser}` (кто запустил), `{=User:ID}`
  (пользователь хита — после паузы или на агенте это может быть кто угодно), `{=System:Now}` (время
  сервера; облако RU — UTC+3), `{=System:NowLocal}`, `{=System:Date}`, `{=System:Eol}`,
  `{=System:HostUrl}` (с bizproc 22.200.0).
- **Функции (40).** Даты: `dateadd`, `datediff`, `date`, `locdate`, `strtotime`, `settime`,
  `workdateadd`, `addworkdays`, `isworkday`, `isworktime`, `touserdate`, `getuserdateoffset`. Числа:
  `abs`, `intval`, `floatval`, `numberformat`, `min`, `max`, `rand`, `round`, `ceil`, `floor`.
  Строки: `substr`, `strpos`, `strlen`, `trim`, `strtolower`, `strtoupper`, `ucwords`, `ucfirst`,
  `urlencode`, `randstring`. Множественные значения: `implode`, `explode`, `merge`, `shuffle`,
  `firstvalue`, `swirl`. Прочее: `if`, `getdocumenturl`. У новых указана версия bizproc (21.200–22.500).
- **Ловушки дат.** Число единиц для `dateadd` из переменной передают только склейкой:
  `{=Variable:n} & "d"`. `datediff` возвращает компоненты интервала, а не итог; итог в днях — только
  `%a`. `workdateadd` считает по рабочему времени пользователя (с bizproc 19.0.0).
- **Модификаторы.** Через `>` внутри скобок, несколько — через запятую. Вывод: `printable`, `friendly`,
  `name`, `server`, `local`, `responsible`, `publink`, `shortlink`, `src` (в коробке небезопасен).
  Преобразование: `bool`, `date`, `datetime`, `double`, `int`, `file`, `select`, `string`, `text`,
  `user`. Суффикс `_printable` у кода даёт печатный вид; приписка `(текст)` у имени поля нужна для
  полей «не для печати» (телефон CRM), иначе в текст попадёт «Array».
- **Коды.** Пользователь — `user_N`; группы — `group_G7`, `group_U7`, `group_IU7`, `group_D7`,
  `group_DR7`, `group_Dextranet`, `group_UA`, `group_SU7`, `group_SG7_A/E/K`. Код группы в поле для
  одного пользователя даёт её пользователя с наименьшим ID. Привязки CRM из не-CRM действий:
  `C_`, `D_`, `L_`, `CO_`, `SI_`, смарт-процесс — `T` + ID типа в шестнадцатеричном виде строчными.
- **Ссылки.** На задание — адрес страницы процесса с `{=Workflow:ID}`; на текущий документ —
  `getdocumenturl('bb')`; на файл — модификаторы `publink`, `shortlink`.
- **Одно «Изменение документа» видит старые значения.** Выражение, зависящее от поля, которое меняется в
  том же действии, получит прежнее значение (5359).
- **Пять ошибок проектирования (8445).**
  1. Несколько «Изменений документа» подряд — лишняя нагрузка; менять поля одним действием.
  2. Цикл без надёжного выхода — копятся экземпляры; нужен аварийный выход по времени или счётчику.
  3. Опрос статуса в цикле с паузой — вместо него «Ожидание стадии сделки».
  4. Паузы и задания в процессе «при изменении» — пока он ждёт, документ меняют снова; такой процесс
     должен сразу отработать и завершиться.
  5. «Параллельное ожидание действия» без ветки с «Паузой» — процесс зависает, если никто не нажал
     команду.

## Ошибки в уроках
- 3814: в примере `{Document:ID}` без `=`.
- 4912: пример `strtotime("next Thursday")` даёт неверную дату; в синтаксисе `getdocumenturl` не закрыта
  скобка.
- 12383: поля фамилии и отчества контакта, по-видимому, перепутаны.

## Открытые вопросы
- Семантика оператора `%` — в уроке без примера.
- В чьём часовом поясе `{=System:NowLocal}`, когда процесс идёт на агенте.
